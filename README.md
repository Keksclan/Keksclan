# Hi, I'm Til

I build authentication infrastructure and backend systems for distributed microservice environments.

My main focus is designing and implementing OAuth2/OIDC-based architectures that are secure, scalable, maintainable, and fast under real-world load.

---

## What I work on

* OAuth2 / OpenID Connect Authorization Servers
* JWT & Opaque Token validation
* Token Exchange & service-to-service authentication
* Multi-tenant IAM systems
* Permission and ACL systems
* gRPC-based microservice communication
* Client, Tenant and User service architectures
* Key rotation, encryption metadata and secure secret handling
* Introspection, JWK handling and token lifecycle management
* Performance-oriented auth validation with caching

Most of my work is backend-heavy, security-focused and infrastructure-driven.

---

## Current Direction

Designing modular IAM systems for distributed environments:

Authorization Server
→ Client Service
→ Tenant Service
→ User Service
→ Permission / ACL Service
→ Resource Services

The goal is simple:

auth that is correct, fast, secure and maintainable.
